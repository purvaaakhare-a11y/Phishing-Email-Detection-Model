# 🎣 Phishing Email Detection Model

A machine learning-based cybersecurity tool that detects phishing emails by analyzing textual content and suspicious patterns.

## Features
- Email classification as **Phishing** or **Safe**
- TF-IDF text feature extraction
- Machine Learning using Scikit-learn
- Accuracy score evaluation
- Confusion matrix generation
- Real-time email prediction from user input

## Setup
pip install -r requirements.txt
python train_model.py
python email_classifier.py

## Sample Dataset Format
text,label
"Verify your account immediately","phishing"
"Project meeting tomorrow","safe"
